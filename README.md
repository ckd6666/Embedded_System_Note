# Embedded System Note

A personal repository for embedded systems learning, organized around projects, reusable knowledge, and AI working rules.

## Structure

```text
Embedded_System_Note/
├── README.md
├── projects/
├── knowledge/
└── skills/
```

- `projects/` — Project records and related code.
- `knowledge/` — Reusable technical knowledge.
- `skills/` — Rules for AI working with this repository.

Top-level modules are independent. When working in one module, do not modify another module unless explicitly requested.
