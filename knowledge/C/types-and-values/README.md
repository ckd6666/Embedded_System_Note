# Types and Values

The C type system and the meaning of values before hardware-specific representation concerns.

## Scope

- fundamental arithmetic types
- `char`, integer, floating, and Boolean types
- `typedef`
- `enum`
- qualifiers as type properties
- conversions at a conceptual level
- type compatibility and value categories where useful

Detailed integer conversion rules belong in `../integers-and-bits/`. Object memory layout belongs in `../objects-and-data-layout/`.

## Look Here When

You need to determine what a declaration means, what type an expression has, or how a C type should be modeled.
