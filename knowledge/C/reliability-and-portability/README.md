# Reliability and Portability

Language behaviors and engineering rules that determine whether code remains predictable across optimization levels, compilers, targets, and projects.

## Scope

- undefined behavior
- unspecified behavior
- implementation-defined behavior
- compiler optimization interactions
- diagnostics and warnings
- portability assumptions
- defensive coding
- static analysis
- MISRA C and SEI CERT C guidance

Undefined behavior should also be explained next to the concept that causes it in the owning module.

## Look Here When

Code changes behavior under optimization, across compilers/targets, or violates a safety/reliability rule.
