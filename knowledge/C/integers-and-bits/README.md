# Integers and Bits

Integer semantics and bit-level operations used heavily in embedded C.

## Scope

- integer widths and ranges
- `stdint.h` fixed-width types
- signed and unsigned behavior
- integer promotions
- usual arithmetic conversions
- overflow and wraparound
- bitwise operators
- shift operators
- masks, set/clear/toggle/test patterns

## Look Here When

A numeric expression, comparison, shift, bit mask, or register field produces an unexpected value.
