# 06 — Pointers and Memory

Address-based access, pointer semantics, and memory ownership/storage concerns.

## Scope

- pointer fundamentals
- address and dereference
- pointer arithmetic
- pointers and arrays
- pointer-to-pointer
- `void *`
- null pointers
- invalid and dangling pointers
- `const` with pointers
- ownership concepts
- dynamic allocation and deallocation
- memory leaks and double free

Hardware register access belongs in `../10-hardware-access/`. Alignment and representation belong in `../07-objects-and-data-layout/`.

## Look Here When

A pointer causes a fault, an address is invalid, `void *` is involved, or memory ownership/allocation is unclear.
