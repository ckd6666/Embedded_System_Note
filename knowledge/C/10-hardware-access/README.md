# 10 — Hardware Access

C patterns used to interact directly with memory-mapped hardware.

## Scope

- memory-mapped I/O
- `volatile`
- `const volatile`
- typed register access
- register masks and fields
- read-modify-write
- hardware-updated objects
- access width
- write-one-to-clear and similar register semantics
- hardware-visible side effects

Bit arithmetic belongs in `../04-integers-and-bits/`. Shared-state synchronization belongs in `../11-concurrency-and-interrupts/`.

## Look Here When

Peripheral registers, fixed addresses, memory-mapped I/O, or hardware-visible accesses behave unexpectedly.
