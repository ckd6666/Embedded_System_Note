# Initialization

## Purpose

Understand how objects receive their initial values and why initialization rules matter in embedded systems.

## Scope

- explicit initialization
- initialization at declaration
- zero initialization
- static-storage initialization
- automatic objects
- indeterminate values
- hazards of reading uninitialized objects

## Learning Outcomes

After this chapter, you should be able to determine whether an object has a defined initial value and identify unsafe uninitialized reads.
