# Linkage, Static, and Extern

## Purpose

Understand how names refer to the same or different entities across scopes and translation units.

## Scope

- no linkage
- internal linkage
- external linkage
- file-scope `static`
- block-scope `static`
- `extern`
- declarations shared through headers
- hiding implementation details inside a source file

## Learning Outcomes

After this chapter, you should be able to explain the different meanings of `static`, use `extern` correctly, and reason about symbol visibility across multiple `.c` files.
