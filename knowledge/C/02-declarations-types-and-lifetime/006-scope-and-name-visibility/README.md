# Scope and Name Visibility

## Purpose

Understand where identifiers are visible and how nested scopes affect name lookup.

## Scope

- block scope
- file scope
- function scope
- function prototype scope
- nested scopes
- shadowing
- identifier visibility
- reserved identifier awareness

## Learning Outcomes

After this chapter, you should be able to determine which declaration a name refers to at a given point in a program.
