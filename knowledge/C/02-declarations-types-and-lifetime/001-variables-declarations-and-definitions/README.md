# Variables, Declarations, and Definitions

## Purpose

Establish the basic vocabulary used throughout C: identifier, object, variable, declaration, definition, initializer, and type.

## Scope

- identifiers
- objects and variables
- declarations
- definitions
- declaration versus definition
- basic initializer syntax
- reading simple declarations

## Learning Outcomes

After this chapter, you should be able to explain what each part of a declaration means and distinguish a declaration from a definition.
