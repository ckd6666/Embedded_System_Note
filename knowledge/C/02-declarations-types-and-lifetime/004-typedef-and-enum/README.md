# Typedef and Enum

## Purpose

Use named types and enumerations to make embedded C interfaces and state models clearer.

## Scope

- `typedef`
- type aliases
- `enum`
- enumerators
- enum-based states and modes
- naming types for APIs and drivers

## Learning Outcomes

After this chapter, you should be able to read and define common embedded patterns such as typedef-based API types and enum-based states.
