# Fundamental Types

## Purpose

Understand the fundamental types provided by C and what type information means.

## Scope

- `char`, signed and unsigned character types
- `short`, `int`, `long`, `long long`
- signed and unsigned integer type families
- Boolean types
- floating types
- `void`
- type width and range at a conceptual level

## Learning Outcomes

After this chapter, you should be able to choose and read fundamental C types without assuming implementation-specific widths.
