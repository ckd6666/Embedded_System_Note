# Storage Duration and Lifetime

## Purpose

Separate the concepts of where a name is visible from how long an object actually exists.

## Scope

- automatic storage duration
- static storage duration
- allocated storage duration
- thread storage duration as background knowledge
- object lifetime
- scope versus lifetime
- local automatic objects
- local static objects

## Learning Outcomes

After this chapter, you should be able to determine when an object is created, how long it exists, and why scope and lifetime are different concepts.
