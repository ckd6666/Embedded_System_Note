# Const and Type Qualifiers

## Purpose

Understand how qualifiers constrain access to objects and participate in the C type system.

## Scope

- `const`
- qualified types
- read-only intent
- qualification in declarations
- introductory view of `volatile`
- introductory view of `_Atomic`

## Learning Outcomes

After this chapter, you should understand what `const` qualifies and distinguish language-level type qualification from hardware or synchronization semantics.
