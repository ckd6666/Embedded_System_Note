# 09 — Error Handling

How embedded C code detects, reports, propagates, and reacts to failures.

## Scope

- status and result codes
- error enumerations
- return-value checking
- error propagation
- assertions
- timeouts
- retry and recovery patterns
- fail-safe behavior
- hardware and driver failure reporting

## Look Here When

You need to decide how a function or driver reports failure, how callers react, or how timeout/recovery logic should be structured.
