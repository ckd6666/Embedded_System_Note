# Hardware Access

C patterns used to interact directly with memory-mapped hardware.

## Scope

- memory-mapped I/O
- `volatile`
- `const volatile`
- typed register access
- register masks and fields
- read-modify-write
- hardware-updated objects
- access width and hardware side effects

Bit arithmetic belongs in `../integers-and-bits/`. Concurrency semantics belong in `../concurrency-and-interrupts/`.

## Look Here When

Peripheral registers, memory-mapped addresses, or hardware-visible accesses behave unexpectedly.
