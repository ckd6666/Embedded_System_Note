# Pointers, Arrays, and Buffers

Address-based access and contiguous data handling.

## Scope

- pointer fundamentals and dereferencing
- pointer arithmetic
- arrays and array-to-pointer conversion
- multidimensional arrays
- strings as character arrays
- buffers and explicit lengths
- `void *`
- null and invalid pointers
- bounds and lifetime-related pointer hazards

Hardware register access belongs in `../hardware-access/`. Alignment and object layout belong in `../objects-and-data-layout/`.

## Look Here When

A pointer faults, a buffer is corrupted, array indexing is suspicious, or string handling is unsafe.
