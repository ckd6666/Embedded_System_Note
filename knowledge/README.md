# Knowledge

This module contains independent, reusable embedded systems knowledge organized by subject.

## Principles

1. Organize knowledge by subject.
2. Use the roadmap as a classification reference, not as a fixed directory structure.
3. Create subject directories only when needed, using lowercase kebab-case names.
4. Each knowledge entry is a directory named `NNN-name`, using the next available number within its subject. Existing entries are never renumbered.
5. Changes in `knowledge/` must not modify other top-level modules unless explicitly requested.
